# Draf chained attack Jaka

Dibuat memakai built-in image_gen dengan referensi gambar Jaka dari pengguna. Draf ini berisi tiga hit, masing-masing enam frame (18 frame). Ini aset untuk ditinjau; serangan biasa di runtime memakai lembar Attack terbaru milik pengguna.

File: `assets/Generated/Jaka/Concepts/chained-combo-sheet-v1.png`.

## Prompt lengkap

```text
Use case: stylized-concept. Asset type: transparent animation sprite sheet for a 2D side-scrolling pixel-art game. REFERENCE IMAGE: the attached standing young Javanese warrior, to preserve his exact face, brown batik headband, dark brown hair, black embroidered jacket, pale shirt, diagonal tan shoulder bag, brown batik waist cloth, loose dark trousers and sandals. Create the SAME character performing ONE coherent THREE-HIT KERIS CHAIN, facing RIGHT. A keris is a short wavy-bladed Javanese dagger, with one consistent warm brass/brown hilt; keep it the same size and in the same hand in all frames. Deliver exactly 18 full-body frames in a strict 6-COLUMN x 3-ROW evenly spaced grid; no extra characters outside the cells. Every cell is square, identical scale, same camera and same foot baseline; leave room for the dagger and slash trail. Row 1 (six frames, left to right): ready stance, draw elbow back, upward diagonal keris slash, sharp contact pose with a thin gold crescent, follow through, connecting stance. Row 2 (six frames): begin seamlessly from row 1's last stance, twist shoulder back, fast reverse horizontal slash, compact sharp contact pose, follow-through, connecting stance. Row 3 (six frames): begin seamlessly from row 2's last stance, compact wind-up, decisive forward diagonal finishing cut, bright but narrow gold crescent and a few small sparks, recovery, relaxed ready stance. Strong clear anticipation -> active contact -> recovery for each hit; energetic but grounded, no jump or long dash. The head stays recognizable, feet remain near their baseline, and the body never changes proportions. Crisp purposeful pixel clusters, controlled earthy palette, small gold/ivory slash effects only on the active frames, subtle upper-left light. Do not cover his face with effects. Frame 18 should connect back to frame 1. Intended canvas ratio 2:1 for 6 square columns by 3 square rows, ideally 1536 by 768 pixels. Actual fully TRANSPARENT alpha background throughout all cells, no black or brown backdrop, no glow cloud, no checkerboard, no text, no frame numbers, no grid borders, no watermark, no gun, no bamboo spear, no costume redesign.
```
