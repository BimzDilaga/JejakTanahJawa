# Perbaikan Headless, soundtrack dunia, dan durasi waktu

Pembaruan berikutnya: soundtrack malam dan Headless dari pengguna sudah dipasang pada [27 November](UPDATE_2026_11_27.md). Catatan ketiadaan file di bawah adalah status saat 26 November.

- Headless sebelumnya memakai satu fase sementara. Sekarang memiliki **dua bar, masing-masing 64 HP**. Bar pertama memicu tumbang, kamera terkunci, tahan pose terakhir dua detik, lalu reverse untuk bangkit. Fase kedua mengisi HP penuh, tempo 1,25×, dan lebih sering memakai chain ultimate. Kemenangan cerita baru tercatat setelah bar kedua habis. Ukuran karakter tetap 0,62 dari frame persiapan.
- File pengguna `assets/SFX & Soundtrack/Theme song/Theme song siang.mpeg` sebelumnya belum terhubung ke runtime. Salinan OGG sekitar 3:16 kini menjadi musik dunia pagi/siang/sore, mengikuti slider Musik. Konversi membuang gambar sampul dan mempertahankan sumber aslinya. Musik memudar selama dua detik saat malam dimulai; ambience tetap memakai bus terpisah. Dunia tidak memutar theme di atas musik arena boss.
- **Siang dan malam masing-masing 150 detik**, sesuai keputusan pengguna. Pagi dan sore mempertahankan 60 detik, sehingga siklus penuh 420 detik. Perhitungan jam menggunakan durasi per fase, dengan pause/dialog/boss dan kompatibilitas waktu save tetap mengikuti perilaku sebelumnya.
- Konfigurasi musik: `data/world_audio.json`. **Berkas soundtrack malam belum ditemukan**; kolom `night_music` tetap kosong sambil menunggu nama/lokasi file dari pengguna. Malam tetap memiliki ambience angin dan jangkrik. Tidak membuat lagu pengganti tanpa menentukan sumbernya terlebih dahulu.
- Persiapan audio: `tools/prepare_world_soundtracks.ps1 -Ffmpeg <ffmpeg.exe>`; bila file malam sudah tersedia, tambahkan `-NightSource <file>`. Parameter tersebut menyiapkan OGG malam dan memperbarui konfigurasi runtime.

Verifikasi: `final_boss_combat`, `day_night_smoke`, `world_soundtrack`, `night_encounters`, `campaign_persistence`, dan `polish_presentation`. Tes native `world_soundtrack` memastikan lagu benar-benar diputar, merekam sinyal mixer yang berisi musik, serta memeriksa slider Musik menghasilkan keheningan ketika dimatikan. Rekaman QA: `.godot/audio-review/world-day-mix.wav`; screenshot: `.godot/headless-phase-2.png`. Pemeriksaan paket terpisah mencakup lagu, konfigurasi, dua bar Headless dan durasi siang/malam.
